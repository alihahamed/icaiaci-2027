# ICAIACI–2027

Website for the **International Conference on Artificial Intelligence and Advanced Computational Intelligence**, 28–29 January 2027, Yenepoya Institute of Technology, Moodbidri, Karnataka, India.

Live: https://icaiaci-2027.vercel.app

A single static page (`index.html` + `assets/`), no build step. Open `index.html` locally or serve the folder:

```sh
python3 -m http.server
```

Deploy: `npx vercel deploy --prod`
